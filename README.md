# forbidden-pasta 🍝

**forbidden-pasta** is a simple Chrome extension hand-crafted beautifully to stop myself from coding AI Slop. It aggressively block copy-pasting from ChatGPT and Gemini forcing you to type the code yourself and maybe learn a thing or two as you do that.

## Installation:

### prerequisites
[Bun](https://bun.sh) (i like speed and support anthropic (this is a joke))

### build it
```bash
git clone https://github.com/atpugvaraa/forbidden-pasta
cd forbidden-pasta
bun install
bun run build
```

### load it in chrome
1. Open Chrome (or chromium-based browser that supports chrome extensions)
2. Go to chrome://extensions (or browser equivalent)
3. Enable developer mode.
4. Click **Load unpacked**
5. Select the `dist/` folder that was created.
6. Go to your fav clanky and refresh and try it out and git better.
